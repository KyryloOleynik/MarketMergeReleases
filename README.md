## About

**MarketMerge** is an application designed for intelligent price prediction in the e-commerce sector. It allows users to analyze marketplace data, predict product prices, and optimize pricing strategies with easy-to-use tools.

- Import product data from various sources
- Clean and preprocess pricing data
- Predict optimal prices using ready-to-use machine learning models
- Visualize prediction results and price distributions

## Technologies

- CatBoost model
- Node.js
- NER model
- Python (Pandas, NumPy, ...)

## Quick Start

1. Clone the repository:

- git clone https://github.com/KyryloOleynik/MarketMergeReleases.git

2. Install dependencies:

- python -m venv venv
- venv/scripts/activate
- pip install -r requirements.txt

3. Run the application:

- npm start
