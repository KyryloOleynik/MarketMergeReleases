## About

**MarketMerge** is a powerful desktop application that leverages machine learning to revolutionize e-commerce pricing strategies. Built for marketplace sellers, data analysts, and pricing specialists, it combines advanced AI models with an intuitive interface to deliver accurate price predictions and actionable insights.

### Why MarketMerge?

- **AI-Powered Predictions** - Utilize state-of-the-art CatBoost ML models for highly accurate price forecasting
- **Data Intelligence** - Import, clean, and analyze product data from multiple marketplace sources
- **Optimize Pricing** - Make data-driven decisions to maximize revenue and competitiveness
- **Visual Analytics** - Interactive charts and distributions to understand market trends
- **Real-Time Processing** - Fast predictions with minimal computational overhead
- **Cross-Platform** - Works seamlessly on Windows, macOS, and Linux

**MarketMerge** is an application designed for intelligent price prediction in the e-commerce sector. It allows users to analyze marketplace data, predict product prices, and optimize pricing strategies with easy-to-use tools.

## Technologies

- CatBoost model
- Node.js
- NER model
- Python (Pandas, NumPy, ...)

## Quick Start

1. Clone the repository:

- git clone https://github.com/KyryloOleynik/MarketMergeReleases.git

2. Install dependencies:

- python -m venv venv
- venv/scripts/activate
- pip install -r requirements.txt

3. Run the application:

- npm start
